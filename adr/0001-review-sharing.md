# ADR-0001. Публикация обзора по устойчивой ссылке

**Статус** – предложено для планируемого выпуска. Сценарное решение V3.

## Контекст и постановка задачи

Каталог прототипа хранится локально. Другому туристу требуется открыть опубликованный обзор с двух независимых клиентов, в том числе после завершения работы автора.

## Драйверы решения

Доступность публикации получателю, неизменность идентификатора, целостность текста и снимков, ограниченный бюджет.

## Рассмотренные варианты

1. Отправлять путь к локальному файлу. На другом устройстве этот путь не указывает на данные автора.
2. Передавать экспорт с файлами. Получатель может открыть копию, но обновления потребуют повторной отправки.
3. Хранить опубликованный обзор в общем сервисе и передавать ссылку с идентификатором.

## Итог решения

Выбран общий сервис для публикаций. Клиент отправляет текст и вложения во временную область. Сервис проверяет данные и делает обзор видимым только после успешной записи всех частей. Чтение по идентификатору возвращает только опубликованную версию. Каталог для чтения остаётся локальным.

### Последствия и подтверждение

Открытие ссылки требует сети и доступного сервиса. Оценки предполагают готовую среду размещения и хранилище. Отдельное развёртывание потребует пересмотра оценки. Проверки: открыть ссылку в чистом клиенте; запросить неизвестный идентификатор; прервать запись второго снимка и убедиться, что получателю недоступен неполный обзор.
