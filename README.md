# Электронный путеводитель

Учебный проект Е. А. Юденко, группа 434701, по дисциплине «Жизненный цикл разработки программного обеспечения» (БГУИР).

«Электронный путеводитель» – настольное приложение на C++ для самостоятельных путешествий. Его главная особенность – каталог пополняют сами посетители. Турист добавляет место или маршрут, пишет отзыв о прогулке и делится им. Для следующего путешественника такой отзыв служит обзором места или маршрута. В первом выпуске приоритетны публикация обзоров и выбор прогулки по времени. Автор указывает примерную длительность, а читатель задаёт, сколько времени у него есть. Следующий этап – карта с остановками, возможность поставить геометку места и определить своё местоположение с разрешения пользователя.
