# Сколько раз ты сказал «потом»

Учебный проект Юденко Е.А., группа 434701, по дисциплине «Жизненный цикл разработки программного обеспечения» (БГУИР).

Планируется оконное приложение на C++ для Windows. Пользователь вводит возраст, а приложение оценивает количество случаев откладывания дел по учебной модели из лабораторной работы № 1. Интерфейс строится на WinAPI; логика организуется по схеме Model–View–Controller.

## Структура

- `project/` — пустая заготовка для дальнейшей разработки приложения.
- `adr/`, `srs/`, `sdd/`, `docs/` — шаблоны проектной документации исходного учебного репозитория.
- `lab2/` — отчёт по лабораторной работе № 2.

Материалы лабораторной работы № 1 находятся в отдельной ветке `lab1`. Шаблоны исходного репозитория: [BSUIR-SDLC/SDLC](https://github.com/BSUIR-SDLC/SDLC).
