# Электронный путеводитель

Учебный проект Е. А. Юденко, группа 434701, по дисциплине «Жизненный цикл разработки программного обеспечения» (БГУИР).

Планируется программа на C++ для просмотра стран мира, внесённых в базу данных, достопримечательностей этих стран и маршрутов по достопримечательностям. Формат пользовательского приложения и способ отображения маршрута уточняются при согласовании требований.

## Документы проекта

- [Предварительная спецификация требований](srs/electronic-guide-srs.md) — результат лабораторной работы № 3.
- [Модель SysML v2](srs/models/electronic-guide.sysml) и [графические материалы](srs/graphics/) — представление границ системы и макетов интерфейса.
- `project/` — заготовка для дальнейшей разработки приложения.
- `adr/`, `sdd/`, `docs/` — проектная документация и шаблоны исходного учебного репозитория.
- `lab2/` — отчёт по лабораторной работе № 2.
- `lab3/` — отчёт по лабораторной работе № 3.

Материалы лабораторной работы № 1 находятся в отдельной ветке `lab1`. Шаблоны исходного репозитория: [BSUIR-SDLC/SDLC](https://github.com/BSUIR-SDLC/SDLC).
