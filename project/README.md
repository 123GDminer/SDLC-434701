# Электронный путеводитель

Настольное приложение на C++ для Windows 10 и 11. В левой панели отображаются страны из локальной базы SQLite. Выберите страну, чтобы увидеть её достопримечательности и экскурсионные маршруты. При выборе маршрута отображается нумерованный список остановок. Нажмите на остановку, чтобы прочитать её описание.

## Сборка и запуск

1. Откройте папку `project` в VS Code.
2. В терминале PowerShell выполните `./run.ps1`. Скрипт собирает и запускает программу.
3. Для повторного запуска можно открыть `build/bin/Release/ElectronicGuide.exe`. Оставьте рядом с ним файл `catalog.sqlite3`.

Для сборки нужны Visual Studio 2026 или Build Tools 2026 с компонентами C++, CMake и Windows SDK. Приложение использует системную библиотеку SQLite и работает с локальными данными.

## Каталог

В демонстрационной базе три страны. В Беларуси и Италии есть готовые маршруты, а Япония показывает состояние каталога без маршрутов. Можно добавить записи о любой стране.

Чтобы обновить демонстрационную базу, измените [catalog.sql](resources/catalog.sql) и повторите сборку. В таблице `route_stops` поле `position` определяет порядок остановок. Все остановки должны относиться к той же стране, что и маршрут. При запуске приложение открывает базу для чтения.
